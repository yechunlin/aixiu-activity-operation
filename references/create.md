# 创建活动流程

> ⚠️ **以下步骤名称为内部流程标记，严禁直接输出给用户。向用户展示时，只输出表格、询问语句和结果信息。**

---

## 1. 接收用户自然语言描述

用户通过自然语言描述活动信息，例如：
- "帮我创建一个报名活动"
- "社区开展红色行动，需要志愿者，创建一个相关的报名活动，报名填写：姓名，联系方式"
- "春天到了，学校将在本周六（2026-05-09）举办春游行动，希望孩子们踊跃参加，创建一个报名活动，收集孩子姓名，家长姓名，联系方式，参与人数，是否自驾"

---

## 2. 提取并生成活动信息

### 2.1 基础信息

从用户输入中提取以下字段，未提供的按规则自动生成：

| 字段                 | 规则                                                                                        |
|--------------------|-------------------------------------------------------------------------------------------|
| `title`（活动标题）      | 用户提供则直接使用；未提供时根据主题自动生成，2-15字                                                              |
| `brief`（活动描述）      | 用户提供则直接使用；未提供时根据主题自动生成，**50-150字，严禁低于50字或超过150字**                                         |
| `start_time`（开始时间） | 用户提供则直接使用；未提供时取当前 Unix 时间戳（秒）                                                             |
| `end_time`（结束时间）   | 用户提供则直接使用；未提供时取当前 Unix 时间戳（秒）+ 7天                                                         |
| `fields`（报名字段）     | 用户提供则直接使用；**未提供时先赋值 `[]`**，后续根据模板匹配结果决定是否询问。格式见 `references/field_reference.md`。单次上限 20 个 |
| `is_raffle`（关联抽奖）  | 值为 `1 \| 0`。用户描述中主动提出抽奖字眼则赋值为 1，否则为 0，默认 0                                                |

### 2.2 模板匹配

读取 `config/designh5/template_list.json`，将活动的 `title` + `brief` 与各模板的 `des` 字段进行语义匹配，选择**最契合的 1 个**模板：

- **匹配成功**：
  - `template_id` = 模板的 `template_id`
  - `mark` = 模板的 `mark`
  - `post_img` = `{"url": "", "size": "818*1404"}`
  - `scheme` = `{}`（不生成配色，由模板自带）
- **匹配失败**：
  - `template_id` = `0`
  - `mark` = `""`
  - 进入步骤 2.4 处理海报与配色

### 2.3 字段确认（仅模板匹配失败且 fields == [] 时触发）

若模板匹配失败且 `fields == []`（用户未主动提供报名字段），向用户询问：

> 请问活动需要填写哪些信息？比如：姓名，手机号

- **用户明确回答**（如"姓名、手机号、身份证号"）→ 按回答语义生成 `fields`
- **用户不回答** → **等待用户回复**，不做默认填充，窗口保持等待状态
- **用户回答模棱两可 / 不明所以** → `fields` 按兜底规则赋值为 `[姓名(Text), 手机号(Mobile)]`

模板匹配成功时，**不主动向用户询问字段**，字段处理规则如下：
- 若用户已提供 `fields`（非空）→ 按用户提供的字段组装 JSON
- 若用户未提供 `fields`（为空）→ `fields` 保持为 `[]`，由创建脚本自动使用模板默认字段，无需询问用户

### 2.4 海报与配色处理（仅模板匹配失败时触发）

模板匹配失败的情况下，在组装 JSON 前完成以下处理：

- **海报**：主动询问用户"是否有海报图，请提供海报链接"。用户提供了链接则填充 `{"url": "...", "size": "818*1404"}`，未提供则填充 `{"url": "", "size": "818*1404"}`（结构始终一致，url 为空表示待生成）
- **配色**：根据 `title` + `brief` 主动生成 `scheme`，参考 `template/designh5.json`

---

## 3. 组装 JSON 数据

将上述数据填充到标准格式：

```json
{
  "act_type": "designh5",
  "title": "",
  "brief": "",
  "template_id": 0,
  "mark": "",
  "start_time": 1715078400,
  "end_time": 1715683200,
  "post_img": {"url": "", "size": "818*1404"},
  "scheme": {},
  "fields": [],
  "is_raffle": 0
}
```

---

## 4. 活动信息预览

调用脚本创建活动前，以表格形式向用户展示已处理好的活动信息，并询问是否创建。

**展示规则：**
- **模板匹配成功**：不展示"海报"字段
- **`is_raffle == 0`**：不展示"关联抽奖"字段

**表格格式：**

```
| 选项     | 内容                                         |
|--------|--------------------------------------------|
| 活动标题   | {title}                                    |
| 活动介绍   | {brief}                                    |
| 活动开始时间 | {start_time 转日期字符串，如"2026-01-01 00:00:00"} |
| 活动结束时间 | {end_time 转日期字符串，如"2026-01-07 00:00:00"}   |
```

**条件追加字段（必须逐项判断，不满足条件时严禁展示）：**
- `fields` 非空时追加：`| 报名字段 | {fields 摘要，如"姓名、手机号"} |`
- 模板匹配失败时追加：`| 海报 | {post_img 摘要，url 非空则"已提供海报链接"，url 为空则"待生成"} |`
- `is_raffle == 1` 时追加：`| 关联抽奖 | 已开启 |`

展示后询问用户：

> 是否创建活动？

- **用户确认** → 进入步骤 5，调用脚本创建活动
- **用户拒绝或要求修改** → 回到步骤 2 或步骤 3，按用户要求调整对应字段后重新预览

---

## 5. 调用脚本创建活动

1. 将 JSON 数据写入临时文件
2. 调用 `scripts/create_event.py`，管道参数：`{"temp_file_path": "临时文件地址"}`
3. 脚本返回：`{"title": "...", "act_id": "...", "url": "...", "platform": "...", "qr_code": "..."}`
4. **向用户展示创建结果，必须包含以下所有信息（缺一不可）：**

```
标题：{title}
活动ID：{act_id}
活动地址：{url}
平台：{platform}
二维码图片：![二维码]({qr_code})
```

> 可浏览打开二维码，使用微信扫码体验活动！

**说明**：二维码展示优先级——优先使用 Markdown 语法 `![二维码]({qr_code})`；若当前 Agent 环境不支持 Markdown 图片渲染，则改用 HTML 标签 `<img src="{qr_code}" width="200" height="200" />`；若均不支持，则直接展示图片链接 `{qr_code}` 供用户复制访问。

---

## 6. 抽奖解锁引导（仅 `is_raffle == 0` 时触发）

活动创建成功后，若当前活动 `is_raffle == 0`，向用户询问：

> 报名后解锁抽奖权益，可以激活用户参与热情，提升活动传播势能，要解锁吗？

- **用户拒绝**（明确说"不"、"不用"、"算了"等）→ **流程结束**
- **用户同意**（明确说"好"、"要"、"解锁"等）→ **进入编辑流程**，将 `is_raffle` 改为 `1` 后执行更新

---

## 配色生成规则

根据活动主题和氛围，从以下配色方案中选择或调整：

- **正式/商务**：深蓝/深灰主色调（`#303133` / `#409EFF`）
- **春日/户外**：清新绿/暖黄主色调（`#67C23A` / `#E6A23C`）
- **社区/公益**：温暖橙/红主色调（`#F56C6C` / `#E6A23C`）
- **校园/青春**：明亮蓝/绿主色调（`#409EFF` / `#67C23A`）

具体色值格式参考 `template/designh5.json`。

完整字段定义、fileType 映射、options 格式及示例见 `references/field_reference.md`。
